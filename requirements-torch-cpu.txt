# ---------------------------------------------------------------------------
# requirements-torch-cpu.txt — PyTorch, CPU build only.
#
# SegAudit is designed to run on an ordinary laptop with no graphics card.
# The --index-url line tells pip to fetch PyTorch from its dedicated CPU index,
# which is a few hundred megabytes instead of several gigabytes of GPU
# libraries. Install this file FIRST, then requirements.txt.
#
# Two lines, one of which applies to your machine. The text after ";" is an
# "environment marker": pip evaluates it on the machine running the install
# and skips the line if it is false. That is how one file serves every
# platform without anyone editing it.
#
#   * Windows, Linux, and Apple-silicon Macs get the current PyTorch.
#   * Intel Macs (macOS on x86_64) get 2.2.2 — the last PyTorch release ever
#     built for that hardware (PyTorch dropped Intel-Mac builds in 2024).
#     requirements.txt pairs it with the last MONAI and NumPy that support it.
#
# If you have an NVIDIA GPU and want to use it, see docs/05-roadmap.md
# ("GPU path") — do not edit this file for that.
# ---------------------------------------------------------------------------
--index-url https://download.pytorch.org/whl/cpu
torch==2.13.0; sys_platform != "darwin" or platform_machine != "x86_64"
torch==2.2.2;  sys_platform == "darwin" and platform_machine == "x86_64"
